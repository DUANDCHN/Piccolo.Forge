# Security policy / 安全反馈

For a suspected vulnerability, please use the repository's private reporting feature:
[Report a vulnerability](https://github.com/DUANDCHN/Piccolo.Forge/security/advisories/new).
Private vulnerability reporting was enabled on 2026-11-06. If the button
is unavailable, contact the repository owner through an existing private channel and ask
for a reporting route. Do not post exploit details or credentials in a public issue.

Include the affected Forge, Avalonia, .NET and OS versions, a minimal reproduction,
impact and any suggested mitigation. Remove personal data and secrets from attachments.

The maintainer currently prioritizes the latest released version. There is no guaranteed
response time or long-term support commitment for older versions.

疑似漏洞请通过上方私密报告入口反馈；该入口已于 2026-11-06 开启。入口不可用时，先通过已有的
私密渠道联系仓库所有者索取反馈方式，不要在公开 issue 中发布利用细节或凭据。
请提供版本、最小复现和影响说明，上传前清理个人信息。普通界面与使用问题请使用 issue 模板。
