## 能证明什么

Forge 的首个提交 `eef2887` 记录在 2026-08-15 克隆上游，但忽略了上游 Git 目录，没有记录 SHA。
`f671a9a` 在 2026-08-23 将色板生成器迁入本仓，并记载当时重新生成后的文件无差异。
据该时间范围选取上述上游提交，取得全部 7 份主题 JSON（含父主题），使用当前生成器在临时目录
生成两套 `Controls.Colors.axaml`：**两份输出均与当前跟踪文件逐字节相同**。

这是生成数据的内容匹配证据，**不是找回了最初检出的 SHA**；它也不证明所有行为笔记都研究了
这一提交。旧笔记的行号仍应逐项核对，不能统一追溯标成这个版本。

输入原始字节 SHA-256、两份输出统一 LF 后的摘要及核验范围保存在
[reference-manifest.json](reference-manifest.json)。最初本机比较为逐字节相同；跨平台脚本仅忽略
Git 检出和 Python 写出可能产生的 CRLF/LF 差别，不忽略其他字符、BOM 或空白。
核验程序不联网，不修改已有色板；准备输入后运行：

```bash
python scripts/verify-upstream.py
# 也可使用仓库外的参考目录。
python scripts/verify-upstream.py --upstream /path/to/intellij-community
```

更改生成器或上游输入时必须重新比较输出，解释差异，再更新清单；不要仅为让核验通过刷新摘要。

- JetBrains 的[官方 IntelliJ Platform 说明](https://plugins.jetbrains.com/docs/intellij/intellij-platform.html#open-source)
  将平台说明为 Apache 许可的开源项目。
- 固定提交中，主要模型参考
  [`ToolWindowManagerImpl.kt`](https://github.com/JetBrains/intellij-community/blob/38a8934174f7d14c0c939ae140b63b037a3830e5/platform/platform-impl/src/com/intellij/openapi/wm/impl/ToolWindowManagerImpl.kt)
  和度量参考
  [`JBUI.java`](https://github.com/JetBrains/intellij-community/blob/38a8934174f7d14c0c939ae140b63b037a3830e5/platform/util/ui/src/com/intellij/util/ui/JBUI.java)
  的文件头均明确指向 Apache 2.0。
- 7 份主题 JSON 是平台资源输入，本身没有逐文件许可头。保留 Apache-2.0 全文和 JetBrains
  版权归属，并明确 Forge 对映射、色值回退和度量有修改，不将生成数据重新宣称为自有 MIT 内容。
- 固定提交的 [`NOTICE.txt`](https://github.com/JetBrains/intellij-community/blob/38a8934174f7d14c0c939ae140b63b037a3830e5/NOTICE.txt)
  的署名已纳入本仓 [第三方声明](../../THIRD-PARTY-NOTICES.md)，其文件摘要也在清单中。
- 固定提交根 `LICENSE.txt` 是 IDE 开源构建条款，不能把它当成每份源文件的许可证。
  平台声明、源文件头和实际资源范围应结合审查，不能据此为整个上游仓库作统一许可判断。
