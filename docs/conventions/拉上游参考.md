# 拉上游参考

上游是 [JetBrains/intellij-community](https://github.com/JetBrains/intellij-community)。
普通构建和测试不需要上游检出。色板生成与来源核验使用固定参考提交
`38a8934174f7d14c0c939ae140b63b037a3830e5`，核验范围见 [来源核验](../upstream/来源核验.md)。
该提交能复现现有色板，不代表找回了原始检出的身份。采用稀疏检出：

```bash
mkdir -p third_party
cd third_party
git clone --filter=blob:none --no-checkout --depth 1 \
  https://github.com/JetBrains/intellij-community.git intellij-community
cd intellij-community
git -c core.autocrlf=false fetch --depth 1 origin 38a8934174f7d14c0c939ae140b63b037a3830e5
git sparse-checkout init --cone
git sparse-checkout set \
  platform/platform-impl/src/com/intellij/openapi/wm \
  platform/platform-impl/src/com/intellij/toolWindow \
  platform/platform-api/src/com/intellij/openapi/wm \
  platform/platform-impl/src/com/intellij/ide/ui \
  platform/platform-resources/src/themes \
  platform/util/ui/src/com/intellij/util/ui
git -c core.autocrlf=false checkout --detach FETCH_HEAD
cd ../..
python scripts/verify-upstream.py
```

以上是 Bash 命令；PowerShell 可用 `New-Item -ItemType Directory -Force third_party` 代替 `mkdir -p`。
保留 `core.autocrlf=false`，来源输入摘要针对上游原始字节。要看别的目录可用
`git sparse-checkout add <目录>`，不要切换到最新分支覆盖固定参考版本。

**它不进本仓历史**（`.gitignore` 里排掉了）：几百 MB，且它自己有版本管理。
新机器按上面的命令拉一次即可。

## 坑：文件在 tree 里，工作区却没有

稀疏检出目录里偶尔会缺文件（本轮 `platform-resources/src/themes/` 与
`platform-impl/src/com/intellij/ide/ui/` 都遇到过：`git ls-tree` 能列出来，`ls` 却看不到）。
补一次即可：

```bash
git checkout -- platform/platform-resources/src/themes
```

所以**先 `git ls-tree -r --name-only HEAD | grep <文件名>` 确认它在不在库里**，
再判断是不是要往 `sparse-checkout set` 里加目录。

已经追加过的目录（超出 README 那张表的）：

```bash
git sparse-checkout add \
  platform/ide-core/src/com/intellij/openapi/wm \
  platform/editor-ui-api/src/com/intellij/ide/ui \
  platform/util/resources/misc
git checkout
```

`ToolWindowAnchor` / `ToolWindowType` / `ToolWindowContentUiType` 在 `ide-core`，
不在 `platform-api`；`UISettingsState` 在 `editor-ui-api`；
Registry 默认值在 `platform/util/resources/misc/registry.properties`。
